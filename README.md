# Alark Patel — Personal Portfolio

A portfolio for Alark Patel, a cloud security and platform engineer building security platforms as code across AWS, Azure, and GCP.

A responsive, editorial-style portfolio built with plain HTML, CSS, and JavaScript. Warm ivory, forest green, custom architecture artwork, and accessible navigation connect all seven pages.

## Pages

- `index.html`: introduction, selected work, engineering approach
- `projects.html`: seven projects with category filters and expandable details
- `experience.html`: professional experience and training
- `skills.html`: engineering toolkit
- `education.html`: Rutgers education and research interests
- `involvements.html`: mentorship and community
- `contact.html`: email, copy address, LinkedIn, and GitHub

## Local preview

Run `python3 -m http.server 8000` and open http://localhost:8000. No installation or build step is required. Pages also work when opened directly; clipboard availability depends on browser permissions.

## Customize

Edit content in the HTML files, design tokens in `style.css`, and interactions in `script.js`. Google Fonts supplies DM Sans and Manrope, with system font fallbacks. All artwork is CSS and inline SVG; no image assets are required.

## Deployment

The site remains compatible with GitHub Pages. Publish the repository root through your existing Pages configuration.
