# Personal Website – Alark Patel

A modern, responsive portfolio built with HTML/CSS and a terminal-inspired landing experience.

## Features
- Terminal-themed intro on the home page
- Fixed, modern navigation
- Collapsible project sections
- Uniform project cards with centered descriptions
- Mobile-friendly, responsive layout

## Tech
- HTML5, CSS3 (no framework)
- Font Awesome icons

## Structure
- `index.html` – Landing page (terminal UI)
- `projects.html` – Projects grid
- `experience.html` – Experience timeline
- `skills.html` – Skills overview
- `education.html` – Education
- `contact.html` – Contact methods
- `style.css` – Global styles and components
- `script.js` – Minor interactions (e.g., section toggles)

## Run locally
- Open `index.html` directly in a browser, or
- Use VS Code Live Server extension for auto-reload

## Deploy (GitHub Pages)
1. Push to the `master` branch
2. In GitHub: Settings → Pages → Deploy from branch → `master`/`root`
3. Your site will be available at `https://<your-username>.github.io/Personal_website/`

## Customize
- Edit text in the respective HTML files
- Update icons via Font Awesome classes
- Adjust layout, spacing, and colors in `style.css`
